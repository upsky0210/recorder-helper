# 英式指法校正（2026-10-23）

來源：音樂老師提供的「高音笛指法表-1_0.jpg」（第 95 頁完整表），並以「高音笛指法表_0.jpg」的英式基本音域交叉核對。原圖及放大裁切僅供本機核對，不納入公開儲存庫。未使用網路指法或自行推測。

## 校正結果

- A♯4／B♭4：指法 I 為 `1|1011000`，指法 II 為 `1|1011010`；原資料分別為 `1|1011010`、`1|1010110`。
- C♯6／D♭6：`h|1001100|1`，第 1、4、5 孔按住，第 2、3、6、7 孔打開，拇指留一細縫並蓋住笛尾第 8 孔。原資料為 `h|1011011|1`。
- D6：由缺資料補為 `h|101101h`，第 1、3、4、6 孔按住，第 2、5 孔打開，第 7 雙孔只按住大孔，拇指留一細縫。來源未另外標示笛尾孔，不增填第三段。
- 其餘音及替代指法逐孔核對後維持原值。
- 全部 27 音英式資料齊全；「全部的音」16 音、「加半音」27 音可以使用。德式依使用者要求維持隱藏，兩組年級的範圍與暫定標示不變。
- 拇指圖示用上方白縫表示「留一細縫」，雙孔一黑一白表示只按住一個小孔。
- 作品的音高代號、唱名與存檔格式保留。
